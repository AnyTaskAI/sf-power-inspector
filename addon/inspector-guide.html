📋 1-Click Multi-Format Export Workflows

• 📋 Copy (Excel): Copies the active Data Grid rows as Tab-Separated Values (TSV) with clean headers. Directly paste into Microsoft Excel, Google Sheets, or Apple Numbers with zero CSV delimiter confusion or scientific notation mangling.
• 📋 Copy (CSV) & 📥 Export CSV: RFC-4180 standard CSV file export with quote-escaping, suitable for Data Loader or external ETL pipelines.
• 📋 Copy (JSON) & 📥 Export JSON: Exports the raw or flattened Salesforce JSON record array with nested relationship attributes.
• 📋 Copy (IN clause): Automatically extracts the selected column (or ID column) from all visible rows and formats it into a SOQL-ready `IN ('001...', '001...')` clause for instant query chaining.
• 🗑️ Include Deleted (queryAll): Toggling this checkbox queries both active and soft-deleted (Recycle Bin) records, as well as archived Task and Event records.

🤖 100% Free AI Query Studio & SOQL Engine

SF Power Inspector PRO features an advanced, reverse-engineered schema-aware Prompt-to-SOQL engine that synthesizes complex multi-object queries without charging any organization costs or requiring mandatory API keys.

🧠 How the Free AI Engine Works

  1. Introspective Schema Extraction: The engine introspects the active Salesforce object's fields, labels, types, and relationship names (`referenceTo` and `childRelationships`) in real time.
  2. Natural Language Intent Parsing: Analyzes user keywords like "created this month", "amount greater than 50k", "owner email", and "closed won".
  3. Parent Relationship Traversal: Automatically converts phrases like "Account owner name" into `Account.Owner.Name`.
  4. Child Relationship Subqueries: Automatically synthesizes nested subqueries like `(SELECT Id, LastName, Email FROM Contacts)` when child objects are requested.
  5. Safe SOQL Verification: Validates field existence against the target object's describe metadata, preventing `No such column` runtime exceptions.

🔑 Optional Bring-Your-Own-Key (BYOK) AI Models

If you wish to use frontier LLMs for multi-paragraph SOQL reasoning, you can enter your own free API key in the AI Query Studio settings:

  • Google Gemini (Free Tier): Recommended. Generous free tier with fast response times. Get a free key at aistudio.google.com.
  • OpenAI (GPT-4o / GPT-4o-mini): Direct BYOK support with your OpenAI API key.
  • Anthropic Claude (Claude 3.5 Sonnet): High-precision reasoning for complex architectural queries.
  • Local Ollama / Localhost: 100% private, offline LLM inference via `http://localhost:11434`.

🔗 Deep-Linking & URL Router Specification

Every tool in SF Power Inspector PRO supports query parameters for seamless inter-tool linking, bookmarking, and opening directly from external scripts:

📌 Supported URL Parameters by Tool

Tool Page URL Pattern Behavior on Load
Record Inspector inspect-record.html?sobject=Account Queries most recently modified record on Account and opens live inspection immediately.
Record Inspector inspect-record.html?id=001... Directly loads the specific 15 or 18-character Salesforce record ID.
Data Explorer data-explorer.html?sobject=Contact Builds a smart SELECT query using valid fields on Contact and executes it automatically.
Data Explorer data-explorer.html?query=SELECT+Id+FROM+Lead Pre-populates the query editor and automatically runs the query.
Field Manager & FLS field-manager.html?sobject=Case&field=Status Loads Case object and selects Status field with its FLS permissions matrix.
Schema Studio schema-viewer.html?sobject=Opportunity Adds Opportunity entity to the visual ERD canvas immediately.
