    ⬆️ Parent Relationship Queries (Child-to-Parent)
    
            
    
              Traverse up to 5 levels of parent relationships using dot-notation on standard and custom lookups:
            
    
            
    SELECT Id, LastName, Account.Name, Account.Owner.Email, Account.Parent.Industry
FROM Contact
WHERE Account.BillingCountry = 'USA' AND Account.AnnualRevenue > 1000000
    
            
    
              For custom relationships, use __r (e.g. Custom_Object__r.Parent_Field__r.Name).
            
    
          
    

          
    
            
    ⬇️ Child Subqueries (Parent-to-Child)
    
            
    
              Fetch child records in a single SOQL statement by placing a nested SELECT clause using the plural child relationship name:
            
    
            
    SELECT Id, Name, AnnualRevenue,
  (SELECT Id, FirstName, LastName, Email, Title FROM Contacts),
  (SELECT Id, Name, Amount, StageName, CloseDate FROM Opportunities WHERE IsWon = true),
  (SELECT Id, CaseNumber, Status, Subject FROM Cases WHERE IsClosed = false)
FROM Account
WHERE Type = 'Customer - Direct' LIMIT 50
    
          
    

          
    
            
    📋 Excel & Google Sheets Export Best Practices
    
            
    
              Use 📋 Copy (Excel) to copy Tab-Separated Values (TSV) directly to your clipboard. When pasted into Microsoft Excel or Google Sheets, each column aligns into a separate spreadsheet cell, with parent relationships flattened (e.g. Account.Name). Unlike standard CSV files, TSV prevents issues with commas inside addresses, names, or quotes!
