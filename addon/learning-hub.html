🔄 Triggers & Record Save Order of Execution

  1. System Validation (Field types, maximum lengths, required fields).
  2. Before Triggers (Apex before insert / before update) — ideal for field defaulting without extra DML.
  3. Custom Validation Rules (Formulas) and system validation checks.
  4. Duplicate Rules.
  5. Record saved to DB (not committed yet, ID generated).
  6. After Triggers (Apex after insert / after update) — ideal for child record creation & cross-object DML.
  7. Assignment Rules.
  8. Auto-Response Rules.
  9. Workflow Rules (if field updates run, before/after triggers fire one more time).
  10. Escalation Rules.
  11. Processes and Record-Triggered Flows.
  12. Roll-up Summary calculations on parent records.
  13. Database Commit & Post-commit logic (emails sent, EnqueueJobs executed).
